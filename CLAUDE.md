# Live reaction-picker demo

The destination is a small working local reaction picker for finding and copying GIFs and emoji into conversations. The presenter owns product and visual decisions, informed by the audience.

When charting or maintaining the demo map, read [demo context](docs/demo-context.md). For every tracker operation, follow [GitHub conventions](docs/agents/issue-tracker.md). Run this project from its standalone demo checkout so issues go to its own origin.

Read `.env.example` for configuration. Keep actual environment values out of prompts, logs, and commits.
