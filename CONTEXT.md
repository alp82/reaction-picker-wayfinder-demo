# Glossary

- **Query**: the single text the user types to find GIFs. There is exactly one query at a time.
- **Gallery**: the grid of GIF results for the current query. Empty until a query is typed.
- **Tile**: one GIF in the gallery, showing its preview rendition. Clicking a tile copies it.
- **Copy**: placing a GIF on the clipboard. Two outcomes: the animated GIF bytes, or its link.
- **Copy feedback**: a brief bottom toast after a copy, naming which outcome happened ("GIF copied" / "Link copied").
- **Rail**: the sticky left column holding the query, status line, browser note, and Retry.
- **Retry**: the user's manual re-run of the failed query.
